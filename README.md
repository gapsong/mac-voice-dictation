# mac-voice-dictation

Push-to-talk voice dictation for macOS.
Hold a hotkey, speak, release - your speech is transcribed by the remote whisper service and inserted at the cursor of whatever app is focused.

Transcription runs on the shared gpuserver whisper service (`large-v3-turbo`), the same backend used by the BikeOffice dictation.

Status: initial scaffold. Implementation in progress.
